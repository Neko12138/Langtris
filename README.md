# Langtris

This is a game primarily built with AI code. It's modeled after Tetris, but each block represents a letter. A line that's eliminated becomes a line of poetry, a word, or nonsense. At the end of the game, you can export the text using the "Export Text" button at the top. The download location will be your browser's default download location.

You can also play directly via the page deployed on GitHub.

Log about AI are all located in folders name Ai Chat Log.
